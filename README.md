# SIMASIF

Sistem Manajemen Studio Kreatif

Sistem informasi berbasis web untuk mengelola operasional **Flamboyan Studio**: layanan fotografi, pelanggan, pemesanan, jadwal, transaksi pembayaran, workflow layanan, file fotografi, serta dashboard dan laporan.

## Fitur Utama

- **Pelanggan**: memesan layanan tanpa login, mendapat kode unik untuk tracking, upload bukti bayar, dan download hasil foto
- **Pegawai**: kelola layanan, pelanggan, pemesanan dan jadwal, verifikasi pembayaran, update progres layanan
- **Owner**: monitoring dashboard, laporan, audit log, dan manajemen akun

## Teknologi

- Backend: PHP Native
- Database: PostgreSQL
- Frontend: Bootstrap/Tailwind + Vanilla JavaScript
